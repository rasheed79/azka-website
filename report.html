ملاحق تشغيلية وتطويرية

تحديث صور الأنظمة

  • غلاف بطاقة الخدمات: يُحدَّث باستبدال ملف PNG في public/images/ وتعديل المسار في lib/systems.ts إن تغيّر اسم الملف.
  • معرض الأنظمة الثلاثة (مالي، حضور، ميزانية): يستخدم مسارات الصور المخصصة نفسها؛ أي استبدال للملف يُفضّل مع تغيير اسم الملف قليلاً لتفادي التخزين المؤقت للمتصفح.

الشات بوت والذكاء الاصطناعي

  • مفتاح API يُخزَّن في ملف .env.local تحت المتغير ANTHROPIC_API_KEY ولا يُرفع للمستودع.
  • لتعديل شخصية المساعد أو معلومات الشركة: عدّل System Prompt في app/api/chat/route.ts.
  • الإجابات المحلية الاحتياطية تُعدَّل من messages/ar.json و messages/en.json تحت chatbot.answers.

المظهر (فاتح / داكن)

  • الوضع الفاتح افتراضي عند أول زيارة؛ يُحفظ الاختيار تحت المفتاح azka-theme بالقيمتين light أو dark.

نموذج التواصل

  • يتطلب استبدال المعرف التجريبي YOUR_FORM_ID في components/sections/Contact.tsx بمعرف نموذج Formspree الفعلي.

تشغيل المشروع محلياً

  • من جذر المشروع: npm install ثم npm run dev — يعمل عادة على http://localhost:3000 مع إعادة توجيه للغة الافتراضية.
